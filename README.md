# .github

This repository contains organization-wide configuration and profile files for **1ngaOS**.

## Repository Structure

- **`profile/README.md`** - Organization profile that appears on the [1ngaOS organization page](https://github.com/1ngaOS)
- **`CONTRIBUTING.md`** - Contribution guidelines for all 1ngaOS projects
- **`CODE_OF_CONDUCT.md`** - Code of conduct for the 1ngaOS community
- **`LICENSE`** - MIT License for organization-wide files
- **`projects.md`** - Comprehensive catalog of all 1ngaOS projects

## About This Repository

The `.github` repository is a special repository used by GitHub to:
- Display organization profile information (via `profile/README.md`)
- Provide default community health files (CONTRIBUTING.md, CODE_OF_CONDUCT.md, etc.)
- Share organization-wide documentation and resources

## Organization Profile

Visit the [1ngaOS organization page](https://github.com/1ngaOS) to see the organization profile README.
